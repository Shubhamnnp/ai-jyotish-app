### 2.1 Agent Roles & Responsibilities

1. **Specialist Calculation Agent (`SpecialistCalculationAgent`)**:
   - Queries `KundaliChart`, `ShadbalaCalculator`, `AshtakavargaCalculator`, `default_yoga_dosha_engine`, `VargaCalculator`, and `default_dasha_engine`.
   - Generates a strictly typed `DeterministicFactSheet` containing exact planetary degrees, dignities, retrograde/combust flags, 12-house SAV bindus, active Mahadasha/Antardasha, and active Yogas/Doshas.
   - **Hard Invariant**: No mathematical or astronomical values are generated by LLMs.

2. **Shastriya Rule Retrieval Agent (`ShastriyaRuleRetrievalAgent`)**:
   - Executes domain-specific RAG queries over `ShastriyaKnowledgeBase` and indexed classical Granthas.
   - Attaches authentic Sanskrit shlokas, Grantha references, chapter numbers, and foundational astrological principles.

3. **Evidence Verification & Conflict Resolution Agent (`EvidenceVerificationAuditAgent`)**:
   - Acts as an **Independent Audit Agent**.
   - Segregates all astrological influences into:
     - `supporting_evidence`: Factors supporting the queried life milestone (exaltations, kendra/trikona placements, high SAV $\ge 28$, auspicious yogas, favorable dasha).
     - `conflicting_evidence`: Counteracting factors, obstacles, or delays (dusthana 6/8/12 placements, combustion, debilitation, low SAV $< 25$, active doshas).
   - Computes a formulaic, auditable confidence score:
     $$\text{Confidence Score} = \min\left(92.0, \max\left(15.0, \frac{\sum W_{\text{sup}}}{\sum W_{\text{sup}} + \sum W_{\text{conf}}} \times 100\right)\right)$$
   - Documented weighting matrix:
     - Active Mahadasha Lord alignment: Weight 3.0
     - Primary House SAV bindus ($\ge 30$ vs $< 25$): Weight 2.0
     - Planetary Dignity (Exalted vs Debilitated): Weight 2.0
     - Auspicious Yogas vs Afflicting Doshas: Weight 1.5
     - Vargottama Integrity vs Combustion Affliction: Weight 1.0

4. **Synthesis & Explanation Agent (`SynthesisExplanationAgent`)**:
   - Provides honest, balanced explanations under clearly demarcated sections:
     - `१. प्राथमिक गणितीय स्थिति (Deterministic Core Facts)`
     - `२. 🟢 सकारात्मक शास्त्रीय पक्ष (Supporting Astrological Evidence)`
     - `३. ⚠️ शास्त्रीय सत्य व सतर्कता (Challenges, Delays & Prarabdha)`
     - `४. 📜 प्रामाणिक ग्रन्थ साक्ष्य (Scriptural Authority)`
     - `५. ⚖️ निष्पक्ष दैवज्ञ निष्कर्ष (Audit Verdict)`
   - Proposes non-commercial, authentic Vedic remedies (e.g., Aditya Hridaya Stotra, Shiva Panchakshari, Vishnu Sahasranama, Sundarkand, Sattvic lifestyle) based on afflicted planetary karakas.

5. **Master Daivajna Orchestrator (`MasterDaivajnaOrchestrator`)**:
   - Coordinates the 4 agents in strict sequence.
   - Returns a structured Pydantic `DaivajnaConsultationResult` suitable for both direct API endpoints and UI rendering.
